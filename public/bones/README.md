# Bone meshes

`bones.bin` / `bones.json`: OpenSim LaiUhlrich2022 bone geometry from opencap-viewer
(Apache-2.0, see `LICENSE-opencap-viewer.md`), pre-aligned per segment (proximal joint at the
origin, distal joint at (0, -L, 0)). Display only: used by the experimental 3D skeleton view
(ADR-069/070). Not a pose model, not participant data.
