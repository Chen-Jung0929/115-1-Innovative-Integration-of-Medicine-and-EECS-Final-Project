## 目的與研究定位

臺大 115-1 醫學電資創意整合專題，整合物理治療、電腦視覺、軟體工程與生醫研究。
為物理治療師提供一般攝影機的動作觀察、角度時間序列、ROM 與前後測溝通工具。
產品是 academic PoC，不做診斷、治療建議或尚無證據的醫材／臨床準確度宣稱。

## 科學量測規範

1. 2D image-plane geometric angle：影像投影的三點夾角，受視角／遮蔽影響。
2. Clinically defined joint angle：依解剖、量測平面、零位及正負方向定義，須物治確認。
3. Estimated 3D joint kinematics：模型推測的三維資訊，非已校準的真實空間量測。
4. Reference measurement：獨立且明確描述不確定性的參考；人工影像標註只參考影像平面。

V0 已實作的 provisional 定義：髖—膝—踝在膝點的 2D 內夾角 α∈[0°,180°]；另列
`180°−α` 為屈曲 proxy 時必須用獨立定義 ID，不能冒稱臨床屈曲角。
先將 normalized x、y 分別乘來源寬高，再計算角度；不可直接對 normalized xy 求角。
小向量、非有限值、缺點、低信心、出框及不支援視角須標無效；不能用零度代替。
置信度門檻、容忍範圍與濾波策略須版本化，不能任意事後調整以提高驗證結果。

## 輸入、輸出與非功能需求

- MP4 與 live camera 共用核心。時間使用 media timeline；牆鐘只作建立時間。
- 區分 anatomical side、推論輸入鏡像、顯示鏡像；鏡像不能偷偷交換解剖標籤。
- 保存 schema、模型套件／資產識別與 hash、角度定義／QC 版本、輸入尺寸、
  session/source ID、逐影格時間、raw angle 與 validity；未來濾波值另欄保留 raw。
- 無效區間曲線斷開；ROM 只描述觀察到的有效片段，不自動代表最大臨床 ROM。
- 前後比較須一致量測定義、側別、視角與 protocol；不一致須警示，不給改善診斷。
- 效能目標依實際裝置試驗後訂立；目前沒有 FPS 或誤差門檻承諾。
- 預設瀏覽器本地處理，無後端；下載模型與依賴涉及網路需另審。

## 待確認與責任界線

物治端：目標側別、角度／ROM 定義、動作起迄、操作姿勢、可接受誤差。
工程端：模型版本與部署、時間同步、QC／效能基準、CSV schema 與自動測試。
研究團隊：樣本／倫理、標註者訓練、資料授權、參考方法與統計計畫。
雙鏡頭及獨立量測系統是後續研究選項；雙鏡頭不是自動真值。

Task 2 允許資料集無法存取時先完成本機 MP4 流程並揭露未實測；不取消資料集 provenance 與後續驗收需求。
