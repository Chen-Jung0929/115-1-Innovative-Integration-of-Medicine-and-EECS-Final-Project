# Privacy and ethics

Repository 為 Public。此 PoC 不提供診斷或治療建議；研究／展示用途與正式人體研究應分開。
正式招募、錄影或使用可識別人體資料前，由團隊確認適用倫理審查、知情同意、
資料用途／保存期限、撤回與資料管理要求；不得假定教學專題必然豁免。

## 公開與受限資料界線

Public Git 只放程式、文件、合法且不識別個人的測試 fixture 與摘要。
不提交人體影片、臉部影像、聲音、姓名、病歷、受試者對照表、逐影格 landmarks、
私有標註或 session 輸出。去識別 ID 不保證資料已匿名；動作與影像也可能識別個人。
.gitignore 排除常見媒體、CSV、資料／輸出目錄與 .env；JSON 等仍可能被追蹤，
每次 commit 必須人工檢查 `git diff --cached` 與 staged 路徑。不能以 force-add 繞過規則。

## 未來資料流程

預設本地瀏覽器處理、不上傳、不引入遙測。模型下載／CDN、瀏覽器快取與第三方套件
在 V0 前檢查實際網路請求及授權。攝影機須使用者明確操作才啟動，停止即釋放 tracks。
匯出前提示使用者保存位置與內容；提供清除 session 的流程。這些功能本次尚未實作。
研究資料依團隊核准的最小權限儲存、加密、期限與刪除程序管理；不要把 Git 當受限資料庫。

如不慎提交敏感資料：停止推送／分享，通知團隊資料負責人，撤銷外洩憑證，
依事件處理與 Git 歷史清理程序處置；單純刪除最新檔案不能撤回已公開的歷史／副本。
資料集再利用須先核對授權及來源同意範圍，不能以公開下載取代倫理與授權評估。
