# 第 24 輪：即時鏡頭改為整段錄影（開鏡頭到關鏡頭）

使用者希望錄下開鏡頭到關鏡頭的所有畫面（ADR-095，取代第 22 輪「每段各錄一支」）。

## 改動

- 錄影改為每次開鏡頭錄一支原始畫面＋一支含骨架，等待站好、段與段之間也錄；切換前後鏡頭算關掉再開，會開始新的一支。
- 「已保存的量測段」上方列出「整段錄影」：開始時間、長度、下載整段影片（原始／含骨架）、「用完整分析畫面看整段」（超過上傳頁 10 分鐘上限時只提示下載）。
- 每個量測段記住它在整段錄影中的起點，播放時直接跳過去；換段落時同一支影片跳到新位置。播放位置不在該段內時提示，曲線游標夾在段落範圍內。
- 保留最近 3 次開鏡頭的錄影、合計 600 MB 內（先釋放最舊的，最新一支一定保留），單次最長 30 分鐘。
- MediaRecorder 影片片長未知時，先跳到極遠處讓瀏覽器算出片長再跳回，1.5 秒內沒反應也直接跳。

## 檢查與限制

- `npm run typecheck` 通過；`npm test` 42 個測試檔、292 個測試通過（新增錄影記憶體上限）；`npm run build` 通過（既有 bundle 大小提示）；`npm run test:browser` 37 通過、2 個既有條件略過。
- e2e 檢查一次開鏡頭只有一支錄影、兩個量測段都連到它且後一段起點較晚、換段落時播放器的實際時間確實跳到該段起點、整段影片可下載與送完整分析、切頁回來與中途切走後錄影仍在。模擬鏡頭下整段錄影約 6.1 秒。
- 經獨立 agent 審核兩輪：第 1 輪沒過（換段落時影片沒有真的跳過去、記憶體總量、跳轉相容性），修正後第 2 輪通過。
- 錄影進行中的部分不算在 600 MB 內，最壞情況分頁記憶體約 1.1 GB。實體手機、平板、Safari、Firefox 尚未驗收。
