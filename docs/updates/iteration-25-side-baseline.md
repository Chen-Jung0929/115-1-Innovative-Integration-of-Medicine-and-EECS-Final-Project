# 第 25 輪：側面基準線（過外踝、站直鎖定）

使用者試側面動作時問「側面的基準線怎麼沒出現」。確認原因：之前只做了正面基準線（講義 p.5 的「基準線」只寫在正面欄），側面只有腳尖線和軀幹線，並非門檻沒達到。使用者選擇「過外踝的垂直線」（ADR-096）。

## 改動

| 模組 | 內容 |
|---|---|
| `src/biomechanics/lateral.ts` | 純函式。`sideAnchor`：靠鏡頭側腳踝（代替外踝）、小腿長、腳跟→腳尖方向。`measureSidePlumb`：耳、肩、髖相對側面基準線的水平距離（小腿長，+ = 腳尖方向，與鏡像無關）；點位不可靠時只該點 N/A。 |
| `src/motion/baseline.ts` | `createBaselineAnchor` 接受任何同形狀的 policy（`BaselinePolicy`），側面與正面共用同一個鎖定狀態機。 |
| `src/motion/frontalTimeline.ts` | `SIDE_BASELINE_POLICY`；側面時以腳踝餵第二個鎖定器（靠鏡頭側膝 ≤ 20° 才能鎖定），非側面時不餵。第一次即時鎖定之前用整段影片的側面站直取樣（`offlineSideCalibration`，60% 取樣需在 0.08 小腿長內），腳踝離線 > 0.08 小腿長時不量。每格新增 `sideBaseline`、`sidePlumb`、`sideCalibration`；腳不在線的位置時距離 N/A。身分鎖定時一併重置。 |
| `src/motion/frontalCues.ts` | `sideShoulderForwardShank` 0.4（暫定）；蹲下時肩膀超過基準線 →「重心偏前（肩膀超過外踝基準線太多）」，與「上身前傾太多」同時成立時合併為「上身前傾太多（肩膀超過基準線，重心偏前）」；兩則各自去抖動後才合併（`mergeSideCues`），合併時不會重新計時。 |
| `src/visualization/FrontalOverlay.tsx` | 側面畫紅色基準線（標「基準線（外踝）」）、耳朵點、肩到線的紅色虛線與「肩在線前／後 N%小腿長」；提示框在未鎖定時顯示「側面基準線：等個案站直、不動約 1 秒」，腳移開時顯示「腳不在基準線的位置…」（膝與上身檢查照常）；有提示時基準線加粗；圖例加基準線。 |
| `src/app/App.tsx` | 說明文字補側面基準線。 |

## 檢查

- `npm run typecheck` 通過；`npm test` 42 個測試檔、306 個測試通過（新增：腳踝錨點、耳肩髖距離與鏡像、N/A 原因、重心偏前提示與合併、時間軸鎖定／不跟身體動／正面影片不畫側面線、整段影片線的 60% 與 ≤ 35° 規則、腳離線不量、腳移動後重新鎖定且不回到整段影片線、換人時重置、前傾加入時合併提示不閃）；`npm run build` 通過（既有 bundle 大小提示）；`npm run test:browser` 37 通過、2 個既有條件略過。
- 真實影片試跑（非驗收）：多視角健身資料集 subject_010 squat bad side（CC BY、有臉，不放進 repo，轉 H.264 本機測試），官方 Lite 模型。受試者每下蹲之間只站直約 0.5 秒，沒有「站直 1 秒」，所以用整段影片的站直取樣畫線；線在腳踝上、蹲下時不動。整段 229 個側面取樣都有線。腳在整段影片中會慢慢移動，腳踝離線 > 0.08 小腿長（約 3 cm）的取樣不量，因此 201 個中有 59 個不量（蹲下的 93 個取樣中 28 個不量）；量得到的 142 個取樣肩膀距離範圍 −0.09～+0.49 小腿長（站直時在線附近，蹲下時往前），10 個超過 0.4。在 UI 上，這支影片蹲到最低點的取樣多半被既有人物追蹤判為「無法確認是同一人」而暫停判斷，所以畫面上沒有看到「重心偏前」提示；用同一份分析結果離線重算（不經過畫面的追蹤提示），提示框會出現「上身前傾太多」15 格、「上身前傾太多（肩膀超過基準線，重心偏前）」1 格。若個案先站直 1 秒（即時鎖定），則用 0.2 小腿長判斷腳是否移動，不受這個 0.08 限制。
- 正面影片（OpenCap 範例）確認不會出現側面基準線，正面畫面不變。

- 經獨立 agent 審核兩輪：第 1 輪通過但列出應修項目（整段影片線離腳踝 0.15 小腿長仍在量、合併提示會重新計時、缺測試、文件用語），修正後第 2 輪通過；第 2 輪提醒的舊數字已用修正後的程式重算，整段影片線的 60% 規則改用同樣的 0.08 小腿長。

## 限制

- 2D 影像平面幾何，以畫面垂直當鉛垂線（手機需擺正）；腳踝點代替外踝，側面腳尖點常不準。
- 門檻 0.4 小腿長為暫定值，只有一支「錯誤動作」影片、沒有正確動作的側面影片可比較，待醫學組確認。
- 即時鏡頭仍未接上姿勢檢查（只在上傳影片）。
