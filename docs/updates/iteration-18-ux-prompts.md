# 第 18 輪：給使用者的提示（UX）

## 為什麼改

使用者回饋：影片裡只有個案一個人，只是頭被畫面切掉、雙手在胸前交握，畫面卻寫「這一格沒有穩定追到個案（例如被別人擋住、畫面有其他人）」。這句話舉的例子都不是真的原因，使用者也不知道該怎麼改。

## 實際是哪一關沒過

把 squats_raw.mp4 的上方裁掉，讓頭出鏡，再看匯出的 `tracking.state`／`tracking.reasons`：

| 裁掉 | 結果 |
|---|---|
| 320 px（只剩下巴） | 111 筆全部通過；頭部指標 N/A，其他檢查正常 |
| 360 px（頭完全出鏡） | 前 2.5 秒 MediaPipe 找不到人（`no-pose`），蹲下頭進畫面後才開始追蹤 |
| 400 px（肩膀也碰到上緣） | 找不到人 → 肩膀出界、軀幹點不可靠（`unreliable-torso-anchors`）→ 中斷超過 0.65 秒後身分鎖定，之後整段暫停 |

所以不是「有別人」，而是「頭／肩膀不在畫面內」。MediaPipe 是先找臉再找身體，頭不在畫面裡就常常整個人都找不到。

## 改了什麼

- 提示依真正原因顯示，並附上做法（一行內）：

| 情況 | 影片上傳時的提示 |
|---|---|
| 頭被切掉 | 頭沒有完整入鏡：手機往後移，讓頭入鏡 |
| 找不到人 | 偵測不到人：請讓頭到腳都入鏡（含頭頂） |
| 頭和腳都被切掉 | 人離鏡頭太近：手機往後移，頭到腳都入鏡 |
| 腳被切掉 | 腳沒有入鏡：手機往後移或放低 |
| 左右超出畫面 | 身體超出畫面邊緣：請站到畫面中央 |
| 真的有其他人 | 畫面有其他人：只留個案一人入鏡 |
| 軀幹點看不清 | 看不清楚身體：光線要足、軀幹別被遮住 |
| 剛恢復追蹤 | 確認是同一人中：請稍候 |
| 其他中斷 | 追蹤中斷：個案需一直留在畫面內 |

- 身分鎖定後，提示框寫「頭沒有完整入鏡，之後暫停判斷」，上方橫幅寫完整原因與重拍做法（不再出現「人物一致性」「局部膝部缺點」等術語）。
- 數值卡片下的小字也改用同一個原因（例如「頭沒有完整入鏡」，不再是「還在確認是不是同一人」）。
- 即時鏡頭的狀態列與「這一段已結束」通知用同一套原因（例如「畫面有其他人，這一段已結束並保存在下方…」）。
- 提示至少維持 0.5 秒才會換，不會每格閃動。
- 畫面上的文字拿掉「講義 p.X」頁碼。
- 追蹤條件沒有放寬（理由見 ADR-082）。

## 測試

- 單元測試：每個原因的判斷與文字、不出現英文代碼或頁碼、長度 ≤ 19 字、0.5 秒不閃動、鎖定後沿用原因。
- e2e：即時鏡頭第二人入鏡時的通知改為逐字比對新文字。
