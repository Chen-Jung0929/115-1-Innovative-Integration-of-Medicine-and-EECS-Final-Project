# 第 18 輪：給使用者的提示（UX）

## 為什麼改

使用者回饋：影片裡只有個案一個人，只是頭被畫面切掉、雙手在胸前交握，畫面卻寫「這一格沒有穩定追到個案（例如被別人擋住、畫面有其他人）」。這句話舉的例子都不是真的原因，使用者也不知道該怎麼改。

## 實際是哪一關沒過

把 squats_raw.mp4 的上方裁掉，讓頭出鏡，再看匯出的 `tracking.state`／`tracking.reasons`：

| 裁掉 | 結果 |
|---|---|
| 320 px（只剩下巴） | 111 筆全部通過；頭部指標 N/A，其他檢查正常 |
| 360 px（頭完全出鏡） | 前 2.5 秒 MediaPipe 找不到人（`no-pose`），蹲下頭進畫面後才開始追蹤 |
| 400 px（肩膀也碰到上緣） | 找不到人 → 肩膀出界、軀幹點不可靠（`unreliable-torso-anchors`）→ 中斷超過 0.65 秒後身分鎖定，之後整段暫停 |

所以不是「有別人」，而是「頭／肩膀不在畫面內」。MediaPipe 是先找臉再找身體，頭不在畫面裡就常常整個人都找不到。

## 改了什麼

- 提示依真正原因顯示，並附上做法（一行內）：

| 情況 | 影片上傳時的提示 |
|---|---|
| 頭被切掉 | 頭沒有完整入鏡：手機往後移，讓頭入鏡 |
| 找不到人 | 偵測不到人：請讓頭到腳都入鏡（含頭頂） |
| 頭和腳都被切掉 | 人離鏡頭太近：手機往後移，頭到腳都入鏡 |
| 腳被切掉 | 腳沒有入鏡：手機往後移或放低 |
| 左右超出畫面 | 身體超出畫面邊緣：請站到畫面中央 |
| 真的有其他人 | 畫面有其他人：只留個案一人入鏡 |
| 軀幹點看不清 | 看不清楚身體：光線要足、軀幹別被遮住 |
| 剛恢復追蹤 | 確認是同一人中：請稍候 |
| 其他中斷 | 追蹤中斷：個案需一直留在畫面內 |

- 身分鎖定後，提示框寫「頭沒有完整入鏡，之後暫停判斷」，上方橫幅寫完整原因與重拍做法（不再出現「人物一致性」「局部膝部缺點」等術語）。
- 數值卡片下的小字也改用同一個原因（例如「頭沒有完整入鏡」，不再是「還在確認是不是同一人」）。
- 即時鏡頭的狀態列與「這一段已結束」通知用同一套原因（例如「畫面有其他人，這一段已結束並保存在下方…」）。
- 提示至少維持 0.5 秒才會換，不會每格閃動。
- 畫面上的文字拿掉「講義 p.X」頁碼。
- 追蹤條件沒有放寬（理由見 ADR-082）。

## 測試

- 單元測試：每個原因的判斷與文字、不出現英文代碼或頁碼、長度 ≤ 19 字、0.5 秒不閃動、鎖定後沿用原因。
- e2e：即時鏡頭第二人入鏡時的通知改為逐字比對新文字。

## 第二輪（評審回饋）

評審發現：真正的問題不只是文字。單人正面深蹲時，上身往前傾讓畫面上的軀幹變短，系統把它當成「換人」，第一次蹲下（約 2 秒）之後整段影片都停止判斷。

| 影片 | 改前可用取樣 | 改後 |
|---|---|---|
| lab_front（正面、雙手交握） | 21 / 110 | 103 / 110 |
| lab_headcut（頭被切掉，使用者的情況） | 21 / 110 | 110 / 110 |
| squats_raw／headcut／feetcut／dark | 111 / 111 | 111 / 111 |

（以已存的點位重播追蹤規則，不重新跑模型。）

改了什麼：
- 身分追蹤：兩腳沒動、小腿一樣長，就當作同一人（不看軀幹長度）；暫停後若腳一直在原位 0.5 秒以上可以恢復。兩個人、腳或骨盆瞬移仍會鎖定（ADR-084，這是放寬一條規則）。
- 頭被切掉：MediaPipe 會把臉的點壓在畫面最上緣，現在用「臉的點太靠近上緣」判斷，就算有追到也會提示「頭沒有完整入鏡：手機往後移，讓頭入鏡」，並且不再出現假的「頭偏離中線」。
- 腳被切掉：顯示「腳沒有完整入鏡：手機往後移，讓腳跟入鏡」，不再一直叫個案站直。
- 膝對腳尖線：接近 0 時寫「膝蓋在腳尖線上」；N/A 寫真正原因。
- 正面拍攝時提醒「正面拍攝會低估膝彎曲；膝角度以側面拍攝較準」。
- 提示框移到影片下方，不蓋住頭；拖動時不閃。
- 「沒有站直不動 1 秒」只在真的沒有時顯示。

截圖：`/mnt/project-files/research/ux-review/builder/`（r2before_*／r2after_*，lab_headcut、lab_front、squats_feetcut，1280 與 390 px）。

## 第三輪（評審回饋）

| 情況 | 改前 | 改後 |
|---|---|---|
| 影片中途剪接成另一個人 | 0.3 秒後當成同一人，用前一人的基準線給出 13 次「重心往右偏」 | 4.1 秒起暫停判斷，橫幅寫「可能換了人」 |
| 個子高、頭髮碰到畫面上緣 | 71 / 111 格「頭沒有完整入鏡」 | 0 格 |
| 頭真的被切掉 | 有提示 | 仍有提示（lab_headcut 66 格） |
| 往旁邊跨一步 | 66 次「重心偏、頭偏」假提示 | 0 次，提示「位置變了：請站直不動約 1 秒，重畫基準線」 |

做法：追蹤時記住「腳踩在哪裡」。腳一步一步移動沒關係，但兩格之間腳突然換位置或兩腳間距突然改變，就當作可能換人並暫停；只有腳回到原來的位置才恢復（ADR-086）。

其他：「醫學組檢查線」改成「姿勢檢查線」、斜角提示縮短為一行、沒畫線時不顯示顏色說明、手機版數字排在 3D 骨架前面、頭的提示和綠色 ✓ 合成一個框。

e2e：全部 33 項通過（含多人測試）；另外提供本機模型與影片後，實際 MediaPipe 與 A/B/C 比較兩項也通過。

## 最後一輪審核修正（reviewer final audit）

- 膝對腳尖線紅字改成「真的有跳出提醒才標紅」，與提醒框一致；站直時超過門檻顯示「站直時不判斷，蹲下才檢查」（膝彎曲 < 30° 不判斷，自訂）。
- 提醒框最多同時顯示 3 則（原本 2 則，左右膝同時內夾時第二膝會被藏起來）。
- 「可能換了人」改為「畫面跳動或換了人：手機固定、同一人重拍」，不再先假設使用者換人。
- 基準線重畫提示改為「個案換了位置：等他再站直約 1 秒會重畫基準線」。
